== 4. where this engine still differs (the 13 sentinel rows) ==
#271 content's computed value: the reference echoes the specified list — 'counter(x)' stays
     'counter(x)', 'counters(x, "-")' stays whole, 'attr(data-x)' becomes its fallback string
     ('""' with none, '"y"' with one), 'none' on a regular element reads 'normal', and url() is
     absolute. This engine evaluates the counter ('0'), drops counters() and attr(), prints 'none',
     and echoes the authored relative url.
#272 four single values: 'offset-rotate: reverse' (S must keep the word, C expands it),
     'text-decoration-skip-ink: all' (the engine holds a flag and prints 'auto'),
     'font-language-override' with no property id (so the cascade never stores it and C says
     'normal'), and 'offset-path' (same: the echo is right, the computed falls back to 'none').
