b261 measured truth — reference engine (Chromium 150 family), inline-style CSSOM + host errors.
Every line below is what the reference answered for the call shown; nothing here is derived from
the specification text. Re-measured in this round with small evaluate_script payloads (one or a few
calls per read), because long joined strings come back mangled.

===== 1. flex-flow: which parts the printer drops =====
The pair it elides against is 'row nowrap' — what the `flex` shorthand carries — and NOT the two
longhands' own initial pair ('row' / 'wrap'). A plain 'wrap' therefore prints, a plain 'nowrap'
does not. When both parts drop, the direction stands alone.

  setProperty('flex-flow', V); getPropertyValue('flex-flow')
  'row nowrap'                => 'row'
  'nowrap'                    => 'row'
  'row'                       => 'row'
  'wrap'                      => 'wrap'
  'wrap-reverse'              => 'wrap-reverse'
  'row wrap'                  => 'wrap'
  'column'                    => 'column'
  'column nowrap'             => 'column'
  'column wrap'               => 'column wrap'
  'column wrap-reverse'       => 'column wrap-reverse'
  'row-reverse'               => 'row-reverse'
  'row-reverse wrap-reverse'  => 'row-reverse wrap-reverse'

===== 2. a shorthand whose every part is initial prints its parts =====
  d.style.setProperty('border', 'medium none currentcolor')
    getPropertyValue('border')       => ''
    getPropertyValue('border-style')  => 'none'
    getPropertyValue('border-width')  => 'medium'
    getPropertyValue('border-top-color') => 'currentcolor'
    cssText     => 'border-width: medium; border-style: none; border-color: currentcolor; border-image: none;'
    getAttribute('style') => the same text as cssText   <-- the attribute is the block's serialisation
    style.length => 17   (12 physical border longhands + the 5 of border-image)
    style.item(0) => 'border-top-width'
  d.setAttribute('style', 'border: medium none currentcolor')
    getAttribute('style') => 'border: medium none currentcolor'   (verbatim until a CSSOM write)
  border-top with the same value => cssText
    'border-top-width: medium; border-top-style: none; border-top-color: currentcolor;'
  border-inline with the same value => cssText
    'border-inline-start: medium none currentcolor; border-inline-end: medium none currentcolor;'
  removeProperty('border') after the write => length 0, getPropertyValue('border-style') '', cssText ''

  The 17-longhand storage is the part this engine does not do (gap #269): it keeps the one
  declaration the page wrote and expands it only on the way out, so length is 1 and item(0) is
  'border'. The attribute text now matches, because both surfaces print through one serializer.

===== 6. the sheet lists =====
  a <style> appended by script joins document.styleSheets, its .sheet exists and its rules are live;
  sheet.ownerNode is the element itself; the element sheets stay in document order;
  an adopted constructed sheet is NOT in document.styleSheets and document.adoptedStyleSheets is a
  real Array holding the very object that went in.

===== 7. text-decoration: the full matrix (printing and grammar) =====
  printed order is: lines (engine order), thickness, style, colour.
  'underline solid red'        => 'underline red'          'underline solid'  => 'underline'
  'solid'                      => 'none'                   'dashed'           => 'dashed'
  'red'                        => 'red'                    '3px'              => '3px'
  'auto'                       => 'none'                   'none solid'       => 'none'
  'blink underline'            => 'underline blink'        'underline blink wavy' => 'underline blink wavy'
  'wavy red underline'         => 'underline wavy red'
  'overline 3px solid blue'    => 'overline 3px blue'
  'line-through wavy green 4px'=> 'line-through 4px wavy green'
  'underline 2px'              => 'underline 2px'          'underline 1.5px dotted' => 'underline 1.5px dotted'
  'underline auto'             => 'underline'  (auto is the INITIAL thickness)
  'underline from-font'        => 'underline from-font'
  'underline 50%'              => 'underline 50%'          'underline -3px'   => 'underline -3px'
  'underline 0'                => 'underline 0px'          'underline 0.0'    => 'underline 0px'
  'underline 0%'               => 'underline 0%'
  'underline calc(2px + 1px)'  => 'underline calc(3px)'
  'underline overline'         => 'underline overline'     'none' => 'none'     'blink' => 'blink'
  'spelling-error'             => 'spelling-error'         'grammar-error' => 'grammar-error'
  computed for 'spelling-error': line 'spelling-error', style 'solid', colour rgb(0,0,0), thickness auto

  refused outright (getPropertyValue reads '' and the longhands keep their initials):
  'underline thick'      'underline 2'          'underline 3px 4px'    'underline auto 2px'
  'underline from-font 2px'   'underline wavy dotted'   'underline none'
  'underline spelling-error'  'grammar-error spelling-error'  'underline underline'  'blink blink'
  'red red'              'underline bogus'
  A write the grammar refuses leaves an earlier valid declaration untouched:
    setProperty('text-decoration','underline solid red') then ('underline thick')
      => line 'underline', colour 'red', length 4
