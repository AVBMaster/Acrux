Every want is what the reference engine answered for the same document; geometry rows are written as relations, so the installed font cannot decide them. The rows that still fail are the tracked gaps: a forced break gives the reference engine a zero-width fragment at the end of the line it closes (#262), a child margin collapsed through a static parent does not move that parent (#263), and the color-mix and animation prints are not folded (#68).
