b272 — text-underline-position is a vertical choice and an optional horizontal one, but the engine modelled it as a single value, so a pair like 'under left' collapsed to one keyword and the computed surface answered the empty string. It is a set of flags now: the vertical (auto / under / from-font) and the horizontal (left / right) combine, 'auto' does not pair with an edge, and 'alphabetic' — which this reference engine refuses — is gone. The specified echo prints the vertical first, so 'left under' reads 'under left'. The underlined words below carry the pairs, so the pixel baseline guards the same ground.
