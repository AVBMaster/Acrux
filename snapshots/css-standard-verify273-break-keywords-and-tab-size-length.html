b273 — three gaps closed against the reference engine. (1) 'break-before'/'break-after'/'break-inside' and their 'page-break-*' aliases had property ids but no style field, so every one of them computed to the empty string and the CSSOM echoed even a rejected value like 'break-before: region'; they are one shared slot per axis now, holding the modern CSS Fragmentation 3 keyword, and the legacy name re-spells 'page' as 'always' and reads the empty string for a modern value it cannot name. (2) A percentage 'vertical-align' serialised the stored fraction, so '20%' read back '0.2%'. (3) 'tab-size' with an 'em'/'rem' length stored the bare number as pixels — '4em' computed '4px' — now it resolves against this element's font like every other length.
