b279 — two places where a value was read as though the engine owned words it does not. The comma form of attr() is the spelling CSS Values 5 gives a fallback, and this engine refused every one of them while accepting the space-separated form the reference engine does not — so 'content: attr(data-x, "y")' painted nothing where the reference engine paints the fallback, and a fallback that is NOT a string ('attr(x, url)', 'attr(x, 5px)', 'attr(x, )') is no content at all: the declaration stays in the sheet and the property computes its initial 'normal'. Second, 'filter' had no value grammar: a bare 'grayscale' without its parentheses, a negative blur and a colour written between the offsets and the radius of a drop-shadow were all stored as specified values that the reference engine never keeps, and a drop-shadow kept the colour wherever the page left it instead of printing it in front of the offsets.
