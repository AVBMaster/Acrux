b276 — 'clip-path' is a shape with an optional geometry box, and the box may be written in front of the shape. The clip parser read the shape's name as everything before the first '(', so 'clip-path: border-box circle(50%)' named a shape called 'border-box circle', found no such thing, and dropped the whole clip — the element drew as a full square while the reference engine clipped it to a circle. The value is now rewritten into the suffix form the parser reads (and the reference engine prints) before it reaches it, which also fixes the echo: the initial 'border-box' is dropped, a non-initial box moves behind the shape, a bare number in a length position gains its 'px', 'inset' collapses four sides to the shortest list that means them, and path()'s data is re-printed the way the engine reads it, in double quotes.
