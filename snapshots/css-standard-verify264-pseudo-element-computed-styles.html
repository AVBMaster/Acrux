b264 — getComputedStyle's second argument. A generated box is a box the page never wrote, and a script can still ask for its style: it inherits from the element it came from, takes the initial value of everything non-inherited (so its 'display' is 'inline' inside a 'block' parent and its 'width' is 'auto' where the element reports its used box), and reports 'none' for a 'content' nobody declared. A name that is no pseudo-element answers an empty block instead of throwing.
