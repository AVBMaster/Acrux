b275 — the specified echo and the content value. 'content' had no grammar at all, so 'content: bogus' was a declaration the engine accepted and printed; it now reads a content list (strings, counter(), counters(), attr(), url() and the four quote keywords, with at most one '/ <string>' alt text) and refuses the rest, while keeping the two-argument attr() this engine supports on purpose. Two adjacent strings are one string by computed-value time ('"a" "b"' computes '"ab"'), and two strings written side by side are still two items in the echo ('"a""b"' reads '"a" "b"'). The three marker properties computed the empty string and are inherited echo properties now. And three values print shorter than the page wrote them, the way the reference engine prints them: 'grid-auto-flow: row dense' is just 'dense', 'mask-position: center' is the pair 'center center', and 'paint-order' prints the shortest list that still says the whole order — which also needed that prefix to be idempotent, because the echo runs through it before the applier does.
