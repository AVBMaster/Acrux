b280 — two surfaces that repeated the page instead of answering it. 'background' echoed its components in the order the sheet wrote them, so 'red url(a.png)' read back with the colour in front; the reference engine prints a layer in the order its own grammar takes the components — image, position / size, repeat, attachment, the two boxes, colour last — and it says only what the page wrote, which is why the longhand map cannot give that answer: a written 'repeat' and a reset 'repeat' look identical there, and the engine keeps the word the page spoke. A computed 'transform' is a matrix rather than the list the page spelled, and this engine printed the list for every function with depth: 'translateZ(10px)' echoed itself, and 'rotate(45deg) translateZ(1px)' collapsed to a 2D matrix that had silently dropped the z offset — a wrong answer wearing the right shape. The product is now built as a 4x4 and printed as matrix() exactly when it is flat, which is what the reference engine does: 'translate3d(1px, 2px, 0px)' and 'rotateZ(45deg)' come back as matrix() and 'scaleZ(2)' does not.
